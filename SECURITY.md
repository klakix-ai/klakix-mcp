# Security policy

Please report security issues in the Klakix MCP server or its OAuth endpoints privately to **support@klakix.com** with the subject "Security". Do not open a public issue.

Include the affected endpoint, steps to reproduce and the impact you observed. We reply within 3 working days and tell you when a fix is live.

In scope: `https://klakix.com/api/mcp`, `https://klakix.com/api/oauth/*`, `https://klakix.com/.well-known/*`, `https://klakix.com/oauth/authorize`, and the same paths on `aivideoyap.com`.

Out of scope: denial of service, automated scanner output without a working proof, and social engineering.
